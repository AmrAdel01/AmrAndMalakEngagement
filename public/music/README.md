# Background music goes here

Add your song file as:

    Perfect - Ed Sheeran.mp3

The site is configured for **Ed Sheeran - Perfect** in `src/data/eventData.js`.

Use a file you own or are licensed to use (e.g. purchased download). Keep this filename or update `music.src` in eventData if you use a different one.

Music starts automatically when a guest taps **Begin** on the welcome screen.
